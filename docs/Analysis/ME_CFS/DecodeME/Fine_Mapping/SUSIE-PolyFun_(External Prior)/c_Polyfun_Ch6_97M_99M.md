# Polyfun Chr6 97M-99M



I applied PolyFun[@weissbrod2020functionally] SUSIE[@wang2020simple] fine-mapping to the second DecodeME GWAS-1 signal[@genetics2025initial] on Chromosome 6 using the same methodology as I used on the [chromosome 1 locus](a_Polyfun_Chr1_173M_174M_Locus.md). Unfortunately, and in contrast to my [earlier results](../SUSIE/c_Chr6_97M_99M_Locus.md) when I used SUSIE with a uniform prior on the same locus, this PolyFun-prioer SUSIE analysis produced no credible sets.  It is difficult to say to what we should attribute this result.  It may be that the PolyFun prior and the significant patterns + LD structure favor different variants at this locus, so that combining the two sources of information produce an inconclusive result
