# Polyfun Chr6 26M-27M



I applied PolyFun[@weissbrod2020functionally] SUSIE[@wang2020simple] fine-mapping to the first DecodeME GWAS-1 signal[@genetics2025initial] on Chromosome 6 using the same methodology as I used on the [chromosome 1 locus](a_Polyfun_Chr1_173M_174M_Locus.md).  Unfortunately, like my [earlier uniform-prior SUSIE run on the same locus](../SUSIE/b_Chr6_26M_27M_Locus.md), this run produced no credible sets. Given that this locus lies in the HLA region, which is notorious for its complex LD structure, this result is perhaps unsurprising.
